# Executive brief template (Stage 3 extension)

Loaded only on explicit request; not injected during normal specialist execution.

## Preferred structure

- **Title** — short and specific to the decision.
- **Executive Summary** — 2–4 sentences: the situation and the decision needed.
- **Key Points** — 3–6 bullets, each a single decision-relevant fact from the
  source material.
- **Recommendation** — one paragraph, included only when the source material
  supports a clear recommendation. Omit otherwise.
- **Action Items** — concrete next steps, each with an owner or a deadline where
  the source provides one.

Keep the whole brief on one screen. Prefer plain language over jargon.
