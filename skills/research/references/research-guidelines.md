# Research guidelines (Stage 3 extension)

This reference is loaded only when code explicitly requests it. It is not
injected during normal specialist execution.

## Working method

1. **Distinguish claims from evidence.** State each claim, then the basis for it
   (supplied context, or general knowledge).
2. **Prefer specificity.** "Qdrant supports HNSW indexing" beats "there are many
   indexing options".
3. **Identify uncertainty.** Call out where the answer depends on unstated
   assumptions or fast-moving details.
4. **Do not overstate recency.** Without dated evidence in the context, do not
   assert what is "currently" true.
5. **Separate supplied evidence from model knowledge.** If the context contains
   external material, keep its conclusions traceable to it.
6. **Keep findings concise and decision-relevant.** Drop background that does not
   change what the reader would do.
