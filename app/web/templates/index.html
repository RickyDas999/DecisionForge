DecisionForge

Ask a decision-oriented question. One orchestrator routes it to exactly one specialist agent, which returns a structured answer.

Single-hop multi-agent architecture: the orchestrator classifies your request and hands it to one specialist — never a chain, never a loop. Every successful request uses at most two LLM calls (1 routing + 1 specialist); everything else is deterministic Python.

Comparison Agent

Brief Agent
